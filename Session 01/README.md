# Session 01: MySQL einrichten und Datenmodelle lesen

Di 24.11.2026, 18:00–21:15. SOL. Vier Lektionen.

[Zur Kursübersicht](../README.md)

## Ablauf

| Zeit | Inhalt |
|---|---|
| 18:00–18:45 | MySQL Workbench mit MySQL oder MariaDB verbinden; Version und Bestand prüfen |
| 18:45–19:30 | Modellstufen, Schlüssel und Beziehungen an EventStar erklären |
| 19:45–20:30 | Transaktionen und Speicher-Engines vergleichen |
| 20:30–21:15 | Rollback an zwei Engines prüfen und das Arbeitsblatt abschliessen |

Wählen Sie MySQL 8.4 oder MariaDB 11.4 LTS. Die [Installationsschritte](Session%2001%20Theorie.md#installation-und-verbindung) erklären beide Optionen. Die Kursresultate verwenden MySQL 8.4 als Referenz.

Im Kurs arbeiten wir mit MySQL Workbench; andere Clients sind frei wählbar, der Support ist eventuell eingeschränkt.
